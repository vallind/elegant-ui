# Design principles

Elegant UI combines spatial restraint, operational clarity, precise detail, and system-level consistency into an independent visual language.

## Refined, not decorative

Polish comes from proportion, alignment, typography, state quality, and motion—not from excessive effects.

## Semantic tokens first

Components consume semantic colors, dimensions, radii, elevation, and motion. Raw primitives stay inside foundations.

## Complete states

Every interactive component defines its applicable default, pressed, focused, selected, disabled, loading, and error behavior.

## Accessibility is structural

Touch targets, semantics, focus visibility, contrast, font scaling, RTL, and keyboard or screen-reader behavior are part of the component contract.

## One component, one closed loop

A component is complete only when source, sample, bilingual website pages, navigation, CI artifacts, and physical-device validation agree.
