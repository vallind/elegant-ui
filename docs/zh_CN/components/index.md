# 组件总览

Elegant UI V1 共包含 23 个组件，分为四个类别。只有完成 Compose 实现与完整交付闭环的组件才会在网站中标记为可用。

## 基础组件

| 组件 | 用途 | 状态 |
| --- | --- | --- |
| [Button 按钮](./button) | 通过三种强调层级触发即时操作 | 已完成 |
| [IconButton 图标按钮](./icon-button) | 触发紧凑且无障碍的图标操作 | 已完成 |
| Avatar | 表示人物或实体 | 计划中 |
| Badge | 显示状态或数量 | 计划中 |
| Divider | 分隔内容区域 | 计划中 |
| Tag | 标记或分类内容 | 计划中 |
| Tooltip | 解释紧凑控件 | 计划中 |

## 表单组件

Input、Select、Checkbox、Switch、Radio 与 Slider 已纳入 V1 计划。

## 内容组件

Card、List、Table、EmptyState、Modal 与 Drawer 已纳入 V1 计划。

## 导航组件

Navbar、Sidebar、Tabs 与 Breadcrumb 已纳入 V1 计划。
