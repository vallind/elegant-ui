# 设计原则

Elegant UI 将空间克制、操作清晰、细节精确与系统一致性组合为独立的视觉语言。

## 精致，而非装饰堆叠

高级感来自比例、对齐、排版、状态质量与动效，而不是过量特效。

## 语义 Token 优先

组件只消费语义化颜色、尺寸、圆角、阴影与动效；原始值保留在 Foundations 内部。

## 状态完整

每个交互组件都必须定义适用的 Default、Pressed、Focused、Selected、Disabled、Loading 与 Error 行为。

## 无障碍属于结构

触控区域、Semantics、可见焦点、对比度、字体缩放、RTL、键盘与屏幕阅读器行为都是组件契约的一部分。

## 一个组件，一个完整闭环

仅当源码、Sample、双语网站页面、导航、CI 构件与真机验收保持一致时，组件才算完成。
