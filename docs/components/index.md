# Components

Elegant UI V1 contains 23 components organized into four groups. Components become available here only after their Compose implementation and closed-loop delivery are complete.

## Foundations

| Component | Purpose | Status |
| --- | --- | --- |
| [Button](./button) | Trigger immediate actions with three emphasis levels | Available |
| IconButton | Compact icon action | Planned |
| Avatar | Represent a person or entity | Planned |
| Badge | Display status or count | Planned |
| Divider | Separate content regions | Planned |
| Tag | Label or classify content | Planned |
| Tooltip | Explain compact controls | Planned |

## Forms

Input, Select, Checkbox, Switch, Radio, and Slider are planned for V1.

## Content

Card, List, Table, EmptyState, Modal, and Drawer are planned for V1.

## Navigation

Navbar, Sidebar, Tabs, and Breadcrumb are planned for V1.
