# Physical-device validation checklist

Build: Button milestone `0.1.0-button`

- [ ] APK installs and launches
- [ ] No crash during Light/Dark switching
- [ ] Primary, Secondary, Tertiary hierarchy is clear
- [ ] Small, Medium, Large proportions feel balanced
- [ ] All buttons are easy to tap one-handed
- [ ] Pressed feedback is visible but restrained
- [ ] Loading prevents duplicate taps
- [ ] Disabled state is recognizable
- [ ] Leading/trailing icons align optically with labels
- [ ] Text remains readable at increased system font scale
- [ ] Layout remains usable in landscape

Record device model, Android version, display/font scaling, and observations.
